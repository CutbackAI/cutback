# Native source fixture execution

`workflow prepare --fixture-transport` can freeze an ordinary OpenAI Responses
source-bound search as `native-source-fixture-v1`. This is an explicit synthetic
lesson contract. It never grants a live provider transport or verifies real model
quality, customer savings or an invoice. Existing plans omit the default field,
so their serialized content and hashes remain unchanged.

The independent [support-desk application](https://github.com/CutbackAI/support-desk-example)
uses this contract for a complete local search, separate confirmation, real source
diff, checks on two Git trees and rollback lesson. Its new lesson is under
qualification; use the exact documented public source pin when available.

The collector must advertise the matching native fixture readiness contract
before any dataset upload. Both actual dataset provenance and current capture
rights must be synthetic at plan creation, worker admission and every pre-call
authorization. Requesting a synthetic contract does not relabel existing data.
Source bindings, exact request contracts, budgets, independent group splits,
reservations, retained run identity and proposal gates remain required.

Only an explicitly supplied executor with `synthetic_transport is True` can run
these plans. The core rejects a normal executor; the worker blocks a normal live
executor before constructing a native SDK or reserving a call. It retains
`SCRIPTED_NATIVE_REQUIRES_EXPLICIT_SYNTHETIC_EXECUTOR` with zero provider calls
and no automatic retry. Do not clear that stop or requeue uncertain operations.
Example-specific code must construct a closed transport with public fixture
inputs; the marker is an explicit Python host trust boundary, not a network
sandbox for arbitrary executor code.

The initial contract supports plain source-bound OpenAI Responses with evaluator
v3. It rejects routing, conversation, retrieval, compression, judges, prompt
overlays and generated criteria combinations. Those features have separate typed
execution contracts and cannot inherit synthetic authority from this flag.

All completed summaries and recommendations retain the scripted execution
marker, `representative=False` and scripted usage cost origin. Dashboard run
evidence displays a synthetic native execution notice. The ordinary real-quality
regression gate refuses this evidence. An explicit `sample_only=True` check may
verify fixture mechanics and independently confirmed synthetic labels; a source
proposal still requires human review and application checks. It cannot establish
real quality, whole-application savings, an external-consumer inventory or a
production rollout.

Current final source scope passes **38 in 95.38 seconds** under pinned SDK3:
contract/strategy guards, eleven real PostgreSQL workflows and the real TCP
collector/dashboard journey. This includes regressions for duplicate HTTP/root
scanner hints and a native preparation option that formerly accepted, but did not
freeze, a changed minimum case count. Both label and per-field structured metrics
now retain the requested minimum, and invalid values stop before collector I/O.
Default scoped regressions pass. The broader pre-option-fix source passed
**1,281 / 34 skips in 583.33 seconds**. The browser journey checks authenticated
administrator/viewer boundaries, mobile layout and accessibility. Final installed
archives/images and hosted gates remain pending for this change.

The independent source lesson now passes local validation, untouched synthetic
confirmation, an actual source diff, declared checks on both Git trees and exact
rollback. The 16-token negative controls fail quality. Its original source is
unchanged, and the real-quality gate remains closed. Its public dependency pin,
