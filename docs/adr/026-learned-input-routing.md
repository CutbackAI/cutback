# Learn bounded input-size routes from training comparisons

Status: implementation in progress. This is not an accepted feature or a claim
that input size predicts task difficulty.

The existing router executes one explicitly approved native target per input.
Add train-only fitting of its increasing UTF-8 byte boundaries using complete,
paired native observations. Fit on owner-required quality checks and measured
per-call Decimal costs, keeping unknown costs ineligible. Bound the input set,
model set, leaf count and fitting work. Preserve a baseline tail within its
approved input bound; it is a fallback that still needs validation.

The collector must authenticate every retained case against the frozen training
dataset, source plan and canonical call receipt. Missing, redacted, expired,
uncertain, repeated, conflicting or non-training evidence must abstain. Dataset
family exposure checks also apply: relabeling a known test family cannot make it
training data. Source text and outputs remain in the purpose-bound encrypted
store; fitting exposes no content in metadata. Fitting makes no provider calls.

Freeze the fitted policy and training provenance into a separately approved
validation plan. Only one selected candidate can proceed to a separately
approved untouched confirmation. Do not turn fitted training cost into held-out
quality or full task savings. Parent training, fitting/hosting overhead and all
validation/confirmation costs remain visible; unknown components stay unknown.
The ordinary model-literal source editor continues refusing router integration.

Acceptance requires actual native clients through owned transports, PostgreSQL
scope and canonical receipt checks, current content rights, known-test-family
denial, invalid/missing costs, equal-length conflicting outcomes, deterministic
bounded fitting, separate approvals and untouched confirmation, outage recovery,
CLI/private output, authenticated dashboard/mobile/accessibility, final installed
archives, recovery and public-source gates. No paid calls or production changes
are authorized by this design.
