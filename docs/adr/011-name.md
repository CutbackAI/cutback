# ADR-011: Brand and namespace remain provisional

Accepted. On 23 October 2026 the public PyPI project URL returned HTTP 404 through the web lookup. That is not proof of availability, ownership, reservability or publication permission. No package has been published. The handoff identifies an existing cutback.video company; trademark/legal/handle clearance remains with the founder/release owner. Brand strings are localized to packaging/CLI/docs, not external infrastructure assumptions.

Publication update: `cutback==0.1.0.dev0` was subsequently published through GitHub Trusted Publishing. PyPI publicly lists `moezali` as maintainer, and a clean real-index installation was verified. Package registration is complete for this initial development release; trademark review remains open. See https://pypi.org/project/cutback/0.1.0.dev0/.
