# ADR-007: Preserve independent evidence tiers

Accepted as an invariant; experiment implementation is pending. Static findings are discovered hypotheses. Synthetic SDK fixtures prove code contracts, not real usage/quality. Provider-reported observed tokens with a public catalog yield modeled expense, not invoice totals. No labels means semantic quality NOT VERIFIED. Later evaluations require immutable authorized datasets and grouped held-out splits before any verified recommendation. No runner or judge is stubbed as complete.
