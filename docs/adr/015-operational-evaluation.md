# ADR-015: Operational/evaluation boundaries

PostgreSQL is canonical for events/control/jobs. Encrypted file/S3 artifacts hold examples and prompt/rubric variants outside analytical rows. Metadata retains hashes/provenance and explicit unknowns.

Row/advisory locks protect quotas, maintenance and leases. Hash approval authorizes one run; reservations precede every request and survive uncertain billing. Crashed billable operations fail rather than automatically replaying.

Duplicate/customer groups precede stratification and grouped uncertainty. Verification is limited to independent metrics, adequate sample/group scope and representative held-out evidence. Judges stay provisional. Source-bound patches include rollback and never deploy.

Synthetic local acceptance does not replace customer pilot, rights/budget approval or remote operations. Broader language/enterprise/commercial features follow M8.
