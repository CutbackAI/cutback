Executed release evidence is in [public acceptance](evidence/public-acceptance.md) and its manifest. Ordinary inference is synthetic. No production deployment, paid inference, customer payload capture, live model change or commercial infrastructure provision has occurred. Capture tests use only synthetic fixtures.

Reproduce: `uv sync --locked --all-extras --dev`; Ruff check/format; mypy; `scripts/check.py`; `scripts/scanner_benchmark.py`; `scripts/backup_restore.py --drill`; build and wheel smoke. Browser tests additionally need npm dependencies/Chromium and `CUTBACK_TEST_BROWSER=true`. Legacy SDK cases run separately with OpenAI 1.55.3/Pydantic 2.10.6 rather than substituting SDK versions.

External decisions: approve an isolated staging collector and application diff; authorize a small real provider request with permitted data/vendor/dollar cap; supply rights-cleared examples and meaningful independent quality criteria; review staging evidence before any canary/production change; complete brand review before major launch. Existing approvals are reused within their scope.

Current dev2 local acceptance: **153 passed, four legacy-version cases skipped** with authenticated browser/axe/mobile/PKCE and native isolated CPU training enabled. The separate OpenAI 1.55.3/Pydantic 2.10.6 suite passed **21 tests**. Native Node SDK passed **9 tests**, TypeScript compatibility passed, and the browser import parser passed **3 tests**. Helm default/opt-in manifests passed strict Kubernetes schema checks; Terraform validation and one mocked plan passed without contacting a cluster.

The final local Compose image upgraded to schema **0004**. Encrypted backup/restore matched **33 tables**. The full synthetic experiment walkthrough produced 64 actual collector observations and two paired worker reports, then deleted its own project/artifacts. The capacity smoke durably accepted **10,000 synthetic events and 10,000 duplicate replays**, preserved unknown pricing, and queried usage in 664 ms on this local Windows/Docker run. This is one bounded smoke, not a production SLA. See [completion ledger](product-completion.md).

[Hosted CI](https://github.com/CutbackAI/cutback/actions/runs/40088987906) and [security](https://github.com/CutbackAI/cutback/actions/runs/40088987920) passed on the reviewed dev2 code.
