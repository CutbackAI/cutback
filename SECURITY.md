# Security

Pre-alpha development release. Not production-ready.

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/CutbackAI/cutback/security/advisories/new). Do not include credentials or customer data in public issues.

The scanner does not execute source. Runtime telemetry is metadata-only, with strict scoped authentication. No content capture is supported. See docs/security-and-privacy.md and docs/limitations.md.
