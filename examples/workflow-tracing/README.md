# Synthetic workflow investigation

Source checkout only; not in the published `0.1.0.dev5` wheel. Follow [the walkthrough](../../docs/workflow-tracing.md) to ingest a four-step support workflow and a delayed failing external task check. No model credential, model download or paid request is used. `CUTBACK_PROJECT_TOKEN` is a staging ingestion credential for your own collector and is never printed.

```sh
python sample.py --dry-run
python sample.py --endpoint http://127.0.0.1:8080
```

Expected dashboard path: Traces → Browse sessions → Open session → Open trace. See the agent root, retrieval step, failed `lookup.order` tool, and LLM-shaped step. These are synthetic metadata observations, not native inference or replay. The task check is externally asserted, and full cost/coverage stay unknown.

`openinference-v1.json` was generated by the real pinned SDK and semantic convention package. Its synthetic content attributes and span names deliberately exercise projection; they must not be retained by the metadata collector. `producer-versions.json` records the versions. The fixture has fixed historical times and IDs; `sample.py` supplies a fresh trace/session identity and rebases the intervals before upload. Running the sample twice intentionally creates two sessions.

Regenerate the fixture in a separate environment, without changing the product's native SDK pins:

```sh
python -m venv .producer-venv
.producer-venv/Scripts/python -m pip install opentelemetry-sdk==1.45.1 opentelemetry-proto==1.45.1 opentelemetry-exporter-otlp-proto-common==1.45.1 openinference-semantic-conventions==0.1.42
.producer-venv/Scripts/python generate_openinference_fixture.py
```

On POSIX use `.producer-venv/bin/python`. Keep the producer environment outside publication inputs or add it to your local ignore policy. The generator uses an in-memory exporter and the installed protobuf encoder; it converts bytes to OTLP JSON hex IDs and performs no network export. This fixture qualifies the documented metadata projection, not an arbitrary Phoenix database export or all OpenInference integrations.
